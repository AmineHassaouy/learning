# المقدمة

يعد إعداد بيئة تطوير مناسبة خطوة أولى حاسمة في رحلتك لتصبح مطوراً. ستجعل البيئة المُهيأة جيداً تجربة البرمجة الخاصة بك أكثر سلاسة وكفاءة ومتعة. في هذه الوحدة، سنرشدك خلال عملية إعداد الأدوات الأساسية التي تحتاجها لبدء كتابة كود JavaScript.

سنركز على مكونين رئيسيين:

1.  اختيار وإعداد محرر أكواد أو بيئة تطوير متكاملة (IDE).
2.  تثبيت Node.js و npm (مدير حزم Node)، وهما أساسيان لتطوير JavaScript الحديث.

بنهاية هذه الوحدة، سيكون لديك بيئة تطوير JavaScript تعمل بشكل كامل، بغض النظر عما إذا كنت تستخدم Windows أو macOS أو Linux.

---

# اختيار بيئة التطوير المتكاملة (IDE)

عندما يتعلق الأمر بكتابة الكود، فإن اختيار محرر النصوص أو بيئة التطوير المتكاملة (IDE) هو أمر شخصي. هناك العديد من الخيارات الممتازة المتاحة، ولكل منها نقاط قوته وميزاته الخاصة. تشمل بعض الخيارات الشائعة بين مطوري JavaScript ما يلي:

*   Visual Studio Code (VSCode)
*   Sublime Text
*   Atom
*   WebStorm
*   Vim
*   Emacs
*   Notepad++

المحرر الأفضل هو في النهاية ذلك الذي تشعر بالراحة الأكبر عند استخدامه. إذا كنت معتاداً بالفعل على محرر معين، فلا تتردد في مواصلة استخدامه طوال هذه الدورة.

ومع ذلك، إذا كانت هذه هي تجربتك الأولى في البرمجة أو كنت مبتدئاً في تطوير JavaScript، نوصي بالبدء باستخدام **Visual Studio Code (VSCode)**. وإليك السبب:

*   إنه مجاني ومفتوح المصدر.
*   يتمتع بدعم ممتاز لـ JavaScript جاهز للاستخدام فوراً.
*   يقدم واجهة مستخدم سهلة الاستخدام وغير مربكة للمبتدئين.
*   قابل للتخصيص بدرجة عالية ويحتوي على نظام بيئي واسع من الإضافات (Extensions).
*   متعدد المنصات، ومتاح على Windows و macOS و Linux.
*   يحتوي على ميزات مدمجة مثل IntelliSense (إكمال الكود)، ودعم التصحيح (Debugging)، ومحطة طرفية (Terminal) مدمجة.

لأغراض هذا الدليل، سنقدم تعليمات لإعداد VSCode. ومع ذلك، تذكر أنك حر في استخدام أي محرر تفضله.

# عملية التثبيت لـ VSCode

### 1. Windows
1.  انتقل إلى موقع [Visual Studio Code](https://code.visualstudio.com/).
2.  انقر على زر "Download for Windows".
3.  بمجرد اكتمال التنزيل، قم بتشغيل المثبت.
4.  اتبع معالج التثبيت، وقبول الإعدادات الافتراضية ما لم تكن لديك تفضيلات محددة.

### 2. macOS
1.  انتقل إلى موقع [Visual Studio Code](https://code.visualstudio.com/).
2.  انقر على زر "Download for Mac".
3.  بمجرد اكتمال التنزيل، افتح ملف `.zip` الذي تم تنزيله.
4.  اسحب تطبيق `Visual Studio Code.app` إلى مجلد التطبيقات (Applications).

### 3. Linux
1.  انتقل إلى موقع [Visual Studio Code](https://code.visualstudio.com/).
2.  انقر على زر التنزيل ".deb" (لـ Debian/Ubuntu) أو ".rpm" (لـ Red Hat/Fedora)، اعتماداً على توزيعتك.
3.  بمجرد اكتمال التنزيل، قم بتثبيت الحزمة باستخدام مدير الحزم الخاص بتوزيعتك.
    *   لـ Debian/Ubuntu: `sudo dpkg -i <filename>.deb`
    *   لـ Red Hat/Fedora: `sudo rpm -i <filename>.rpm`

## الإعداد الأساسي والتعرف على واجهة VSCode
بعد التثبيت، افتح VSCode. ستشاهد شاشة ترحيب تحتوي على خيارات لبدء ملف جديد، أو فتح مجلد، أو استكشاف ميزات VSCode. خذ بعض الوقت للتعرف على الواجهة:

*   يحتوي الشريط الجانبي الأيسر على أيقونات لـ: مستكشف الملفات (File Explorer)، البحث (Search)، التحكم في المصدر (Source Control)، التشغيل والتصحيح (Run and Debug)، والإضافات (Extensions).
*   المنطقة الرئيسية هي المكان الذي ستكتب وتعدل فيه الكود الخاص بك.
*   يمكن استخدام اللوحة السفلية لمحطة طرفية مدمجة (Integrated Terminal)، والمخرجات (Output)، ووحدة تحكم التصحيح (Debug Console).

# Node.js و npm

### أ. ما هو Node.js ولماذا نحتاجه؟
Node.js هو بيئة تشغيل JavaScript مبنية على محرك V8 JavaScript الخاص بـ Chrome. يسمح لك بتشغيل JavaScript على جهاز الكمبيوتر الخاص بك خارج متصفح الويب. بينما كان JavaScript يُستخدم تقليدياً بشكل أساسي لتطوير الواجهات الأمامية (Frontend)، فإن Node.js يمكّن JavaScript من الاستخدام أيضاً في برمجة جانب الخادم (Server-side).

بالنسبة لأغراضنا، سيسمح لنا Node.js بتشغيل كود JavaScript مباشرة على أجهزة الكمبيوتر الخاصة بنا واستخدام أدوات تطوير مختلفة مبنية باستخدام Node.js.

### ب. ما هو npm وأهميته؟
npm (Node Package Manager) يأتي مجمّعاً مع Node.js. إنها أداة قوية تتيح لك بسهولة تثبيت ومشاركة وإدارة التبعيات (Dependencies) في مشاريع JavaScript الخاصة بك. يستضيف npm مكتبة ضخمة من الحزم مفتوحة المصدر التي يمكن دمجها بسهولة في مشاريعك، مما يوفر لك الوقت والجهد في التطوير.

### ج. تعليمات التثبيت

#### 1. Windows
**أ. باستخدام المثبت الرسمي:**
1.  انتقل إلى موقع [Node.js](https://nodejs.org/).
2.  قم بتنزيل إصدار LTS (الدعم طويل الأمد).
3.  قم بتشغيل المثبت واتبع معالج التثبيت.

**ب. باستخدام NVM لـ Windows:**
1.  انتقل إلى صفحة إصدارات [nvm-windows](https://github.com/coreybutler/nvm-windows/releases).
2.  قم بتنزيل وتشغيل ملف `nvm-setup.exe`.
3.  اتبع معالج التثبيت.
4.  افتح موجه الأوامر (Command Prompt) الجديد وقم بتشغيل:
    ```bash
    nvm install lts
    nvm use lts
    ```

#### 2. macOS
**أ. باستخدام المثبت الرسمي:**
1.  انتقل إلى موقع [Node.js](https://nodejs.org/).
2.  قم بتنزيل إصدار LTS لنظام macOS.
3.  قم بتشغيل المثبت واتبع معالج التثبيت.

**ب. باستخدام Homebrew:**
1.  افتح المحطة الطرفية (Terminal).
2.  إذا لم يكن لديك Homebrew مثبتاً، قم بتثبيته أولاً.
3.  قم بتشغيل: `brew install node`

**ج. باستخدام NVM:**
1.  افتح المحطة الطرفية وقم بتشغيل:
    ```bash
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash
    ```
2.  أغلق وأعد فتح المحطة الطرفية، أو قم بتشغيل:
    ```bash
    source ~/.bash_profile
    ```
3.  تثبيت Node.js:
    ```bash
    nvm install --lts
    nvm use --lts
    ```

#### 3. Linux
**أ. باستخدام مدير الحزم:**

*   لـ Ubuntu/Debian:
    ```bash
    sudo apt update
    sudo apt install nodejs npm
    ```

*   لـ Fedora:
    ```bash
    sudo dnf install nodejs npm
    ```

**ب. باستخدام NVM (مدير إصدارات Node):**
1.  تثبيت NVM:
    ```bash
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash
    ```
2.  أعد تشغيل المحطة الطرفية أو قم بتشغيل `source ~/.bashrc`.
3.  تثبيت Node.js:
    ```bash
    nvm install --lts
    nvm use --lts
    ```

### د. التحقق من التثبيت
بعد التثبيت، من المهم التحقق من أن كل شيء تم إعدادها بشكل صحيح.

إذا كنت تستخدم NVM، قم أولاً بتشغيل:
```bash
nvm use --lts
```

*   **التحقق من إصدار Node.js:** افتح محطة طرفية أو موجه أوامر وقم بتشغيل:
    ```bash
    node --version
    ```
    يجب أن ترى رقم الإصدار (مثلاً: `v14.17.0`).

*   **التحقق من إصدار npm:** في نفس المحطة الطرفية، قم بتشغيل:
    ```bash
    npm --version
    ```
    يجب أن ترى رقم الإصدار (مثلاً: `6.14.13`).

### هـ. تحديث Node.js و npm

**إذا قمت بالتثبيت عبر NVM:**
1.  تحديث NVM نفسه:
    ```bash
    nvm install-latest-npm
    ```
2.  تثبيت واستخدام أحدث إصدار LTS من Node.js:
    ```bash
    nvm install --lts
    nvm use --lts
    ```

**للتركيبات المباشرة:**
*   لـ Node.js، قم بتنزيل أحدث إصدار من الموقع الرسمي وتثبيته.
*   لـ npm، قم بتشغيل:
    ```bash
    npm install -g npm@latest
    ```
